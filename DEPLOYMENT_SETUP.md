## 🔍 What Happens During Deployment

### Backend Deployment:
1. Render clones your GitHub repo
2. Installs Python dependencies from `requirements.txt`
3. Starts FastAPI with uvicorn
4. Connects to MongoDB Atlas
5. Creates default admin user (admin/admin123)
6. Health check at `/api/health`

### Frontend Deployment:
1. Render clones your GitHub repo
2. Runs `npm install` to get dependencies
3. Runs `npm run build` (creates `dist/` folder)
4. Serves static files from `dist/`
5. Routes all paths to `index.html` (SPA support)

## 🛠️ Deployment Commands Reference

### Backend:
```bash
# Build Command (Render runs this)
pip install -r src/backend/requirements.txt

# Start Command (Render runs this)
cd src/backend && uvicorn server:app --host 0.0.0.0 --port $PORT
```

### Frontend:
```bash
# Build Command (Render runs this)
npm install && npm run build

# Publish Directory
dist
```

## 🌐 After Deployment

Your URLs will look like:
- **Frontend**: `https://portfolio-frontend-xxxx.onrender.com`
- **Backend API**: `https://portfolio-backend-xxxx.onrender.com`
- **API Docs**: `https://portfolio-backend-xxxx.onrender.com/docs`

### Update Frontend Environment:
After backend is deployed, update your frontend's `VITE_BACKEND_URL`:
1. Go to Render Dashboard → portfolio-frontend
2. Environment → Add Variable
3. `VITE_BACKEND_URL = https://your-backend-url.onrender.com`
4. Save changes (triggers re-deploy)

## 🚨 Common Issues & Solutions

### Issue: Backend fails to start
**Solution**: Check Render logs, verify MONGO_URL is correct

### Issue: Frontend can't connect to backend
**Solution**: Verify VITE_BACKEND_URL in environment variables

### Issue: CORS errors
**Solution**: Backend already allows all origins. For production, update [server.py](./src/backend/server.py)

### Issue: 502 Bad Gateway
**Solution**: Backend is starting up (takes 30-60s on free tier)
